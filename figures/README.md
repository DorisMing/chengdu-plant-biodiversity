# Figures and Visualizations

This directory stores figures and visualizations generated during the plant biodiversity analysis in Chengdu, China.

## Planned Figures

1. Plant occurrence distribution map.
2. Plant species richness map.
3. Species diversity visualizations.
4. Other figures for research reports and publications.

## File Formats

Figures may be saved in the following formats:

- PNG
- JPEG
- PDF

## Data Source

Visualizations will be generated using processed GBIF occurrence data.

## Data Management

All figures should be generated from documented analysis scripts.
