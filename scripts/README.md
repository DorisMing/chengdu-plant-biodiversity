
# Python Scripts

This directory contains Python scripts for the analysis of plant biodiversity in Chengdu, China.

## Planned Scripts

### 01_data_cleaning.py
Data cleaning and quality assessment of GBIF occurrence records.

### 02_spatial_analysis.py
Spatial analysis of plant occurrence records.

### 03_visualization.py
Visualization of plant species distributions and biodiversity patterns.

## Programming Language

Python

## Project Workflow

Data acquisition → Data cleaning → Spatial analysis → Visualization
