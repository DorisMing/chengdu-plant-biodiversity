
# Processed Data

This directory stores cleaned and processed plant occurrence records.

## Data Source

Global Biodiversity Information Facility (GBIF).

## Data Processing

The planned data processing steps include:

- Removing duplicate records.
- Checking missing geographic coordinates.
- Identifying invalid coordinates.
- Reviewing taxonomic information.
- Preparing data for spatial analysis.

## Data Management

Processed datasets should be generated from copies of the original GBIF data.

The original data in the raw directory should remain unchanged.
